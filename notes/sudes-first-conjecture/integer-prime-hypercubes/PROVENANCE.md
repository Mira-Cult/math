- `originals/` preserves the UTF-8 scientific source bytes, including dated status paragraphs, historical source identifiers and research-workspace reproduction commands. These archival records are not the current public status page.
- `sources/` contains Markdown reading copies: math delimiters and tags are adapted for GitHub, local dependencies are redirected to this package, and unavailable historical cross-references are labelled rather than presented as working links. No mathematical assertion is deliberately changed. Use original bytes for hash-pinned verification.
- `SHA256SUMS.json` records both original and presentation-copy hashes. `replay.py` adapts only the directory layout; it does not change imported programs, tests or scientific source contents.
- The package includes inherited comparison and partial-result manuscripts to make dependencies understandable. Their earlier candidate/partial status statements are superseded only within the exact scope of the final component and composition review.

The publication is a reviewed conventional proof, not an announcement of formal Lean verification. Internal nonauthor reviews are not formal GitHub approvals or external refereeing. The uniform-frame control reuses an author helper, as disclosed in the public index. A skipped CI workflow is not a successful test run.
