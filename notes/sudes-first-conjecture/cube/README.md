# Supporting proofs for the full signed-line prime cube

These manuscripts support [Manuscript IV](../prime-cube.md), which covers the exact first n³ odd primes and every full signed-coordinate line for every sufficiently large odd order. There is no evaluated cutoff, square-section primality assertion, or growing-dimension permutation theorem.

- [Full integer compatibility and small-order exceptions](signed_incidence.md).
- [Prime target vectors and residue routing](signed_targets.md).
- [Physical cuboid trades, fresh prime tuples, and packing](signed_trades.md).
- [Baseline three-stage axis controller](cube_controller.md).
- [Symmetric exact-total prime targets](cube_targets.md).
- [Axis incidence, bounded integer lifting, and tensor-expander coefficients](incidence.md).

The exact-total [finite prime-list lemma](../explicit-targets.md) and the [bounded-degree graph construction](../controller.md#f-independent-row-and-column-controls) are reused from the public square proof. The baseline axis controller is retained as a separate component; the new composition supplies its additional preservation requirements.
