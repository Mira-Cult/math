## AO1. Theorem

For **every positive odd integer n**, the first n² odd primes can be
arranged, each exactly once, in an n-by-n square so that every row sum,
every column sum and both main diagonal sums are prime. The line sums
may repeat. This is a prime-line arrangement, with no equal-sum condition.

Thus the smallest positive cutoff in the requested all-odd-tail formulation
is **N0=1**. The analytic/construction tail begins at2001; the separate
finite certificate covers every smaller relevant order.

## AO2. Two exhaustive cases

Let n be a positive odd integer.

If n<=1999, apply the [finite-family certificate](cutoff2_finite_remainder_squares.md).
It contains exactly one complete witness for each of the1000 successive
odd orders1,3,...,1999. The decoding starts from the first n² odd primes,
replays a completely specified permutation and finite swap list, then
recomputes and tests every row, column and both diagonal sums. For n=1
the square is [3], and every required line label has prime sum3.

If n>=2001, apply the [complete classical tail](cutoff2_tail2001_theorem.md).
It covers all odd n>=2001, including its bounded controller bands and
the preserved unbounded classical fallback. Every branch has the same
prescribed input pool and the same required lines.

There is no positive odd integer strictly between1999 and2001. These
two cases therefore prove AO1. No missing range is inferred from scattered
examples, probability, or a different prime pool. Neither case presumes
the conclusion of the other.

## AO5. Reproduction

From a complete exported source tree, using Python3 and a compiler with
C++20 support, run:

```sh
python3 -B problems/prime-line-sums/code/verify_sude_all_odd.py
```

The default command validates the exact complete source set, the finite
certificate's compressed and raw identity, the contiguous two-case cover,
and both full component commands. It expects the complete tail status and
the complete finite-family status, and checks their exact numerical scope.
Negative controls reject missing or changed sources, malformed maps,
incomplete order ranges and altered case boundaries. The component commands
also exercise their own arithmetic, certificate and diagonal controls.

`--composition-only` performs the strict source and case checks while
omitting the two long replays. It reports a distinct weaker status and
must not be described as the default full certificate run.

The lower-band proof and finite witnesses exhaust the positive odd orders.
There is no remaining finite interval to search in the stated problem.
Further computational work can improve the efficiency of producing larger
individual squares or formalize the proofs; it is not a prerequisite for
the two-case mathematical conclusion once its exact source review passes.
