# Proof of Claim `0323-finite-simple-non-moufang-bol-loops:C0007`

We build on the canonical faithful folder and nuclei theorems of Claim `0323-finite-simple-non-moufang-bol-loops:C0001`.

### 1. Canonical Inverting Automorphism and $\Lambda^2$-Obstruction Theory

#### Theorem 1.1 (Canonical Inverting Automorphism, $\Lambda^2$-Disjointness, and Master Single-Class Exclusion)
Let $Q$ be a left Bol loop with $N_\lambda(Q) = \{1_Q\}$ (in particular, by `C0001` Theorem 1.5(1), **every simple proper left Bol loop**), and let $(G, H, K) = (\operatorname{LMlt}(Q), \operatorname{LInn}(Q), \{L_x : x \in Q\})$ be its faithful left Bol folder ($G = \langle K \rangle$, $\operatorname{Core}_G(H) = 1$).
1. **Existence and uniqueness of the inverting automorphism $\tau \in \operatorname{Aut}(G)$**: Let $\Xi_K(G) := \{k_1 \cdots k_m : m \ge 1,\; k_i \in K,\; k_1^{-1} \cdots k_m^{-1} = 1_G\}$. If $g = k_1 \cdots k_m \in \Xi_K(G)$, then $k_m \cdots k_1 = (k_1^{-1} \cdots k_m^{-1})^{-1} = 1_G$, so repeated application of $a b a \in K$ (`C0001` Theorem 1.3) gives
   $$g u = (k_1 \cdots k_m) \, u \, (k_m \cdots k_1) \in K \qquad \forall u \in K.$$
   Taking $u = 1_G \in K$ shows $g \in K$, say $g = L_a$ ($a \in Q$). For every $y \in Q$, taking $u = L_y \in K$ gives $L_a L_y \in K \cap L_a L_y H = \{L_{a * y}\}$, so $L_a L_y = L_{a * y}$, i.e. $a * (y * z) = (a * y) * z$ for all $y, z \in Q$. Hence $a \in N_\lambda(Q) = \{1_Q\}$ and $g = 1_G$, proving $\Xi_K(G) = \{1_G\}$. By symmetry ($k_i \leftrightarrow k_i^{-1}$), $k_1 \cdots k_m = 1_G \iff k_1^{-1} \cdots k_m^{-1} = 1_G$, so $k_1 \cdots k_m \mapsto k_1^{-1} \cdots k_m^{-1}$ defines a **unique group automorphism $\tau \in \operatorname{Aut}(G)$** satisfying $\tau(k) = k^{-1}$ for all $k \in K$ and $\tau^2 = \mathrm{id}_G$ (with $\tau = \mathrm{id}_G \iff \exp(Q) = 2$).
2. **Twisted involution union $\Lambda$ and $\Lambda^2$-disjointness**: In the semidirect product $\widetilde{G} := G \rtimes \langle \tau \rangle$ (taking $\widetilde{G} = G$ if $\tau = \mathrm{id}_G$), set $\Lambda := \tau K \subseteq \tau G$. For every $k \in K$, $(\tau k)^2 = \tau(k) k = k^{-1} k = 1$, so $\Lambda \subseteq \mathcal{I}(\tau G) := \{x \in \tau G : x^2 = 1\}$ and $\tau = \tau \cdot 1_G \in \Lambda$. For all $k_1, k_2 \in K$, $(\tau k_1)(\tau k_2)(\tau k_1) = \tau(k_1 k_2^{-1} k_1) \in \tau K = \Lambda$; since $\langle \Lambda \rangle = \langle \tau, K \rangle = \widetilde{G}$, **$\Lambda$ is a union of $\widetilde{G}$-conjugacy classes of involutions in $\tau G$ containing $\tau^{\widetilde{G}}$**, with $|\Lambda| = |K| = [G : H]$. Moreover,
   $$\Lambda^2 = (\tau K)^{-1}(\tau K) = K^{-1} K \subseteq G$$
   is $\widetilde{G}$-conjugation invariant, so $K$ is a left transversal to all $g H g^{-1}$ in $G$ **if and only if $H \cap \Lambda^2 = \{1_G\}$**.
3. **Coset-Generation Obstruction**: If $G_+ \trianglelefteq G$ has index $[G : G_+] = 2$ and $\Lambda \subseteq \tau G$ lies in a single coset of $G_+$ in $\widetilde{G}$, then $K = \tau \Lambda \subseteq G_+ \lneq G$, contradicting $\langle K \rangle = G$.
4. **Master Single-Class Lemma**: Assume $Q$ is finite and proper ($|H| = h = |G| / |\Lambda| \ge 2$). If $G$ has a **unique** conjugacy class $I_1$ of involutions, $\tau G$ has a **unique** $\widetilde{G}$-conjugacy class $\Lambda = \tau^{\widetilde{G}}$ of involutions, and **$h = |G| / |\tau^{\widetilde{G}}| = |C_G(\tau)|$ is even**, then Cauchy's Theorem yields an involution $u \in C_G(\tau) \cap I_1$. Because $(\tau u)^2 = \tau(u) u = u^2 = 1$, we have $\tau u \in \Lambda$, whence $u = \tau(\tau u) \in \Lambda^2$; $\widetilde{G}$-invariance of $\Lambda^2$ forces $I_1 \subseteq \Lambda^2$, so $H \cap I_1 = \emptyset$ while $|H| = h$ is even, contradicting Cauchy's Theorem on $H$. $\square$

### 2. Infinite Lie-Type Simple and Almost-Simple `LMlt(Q)` Exclusions

#### Theorem 2.1 (Exclusion of $\operatorname{PSL}_2(q)$, $\operatorname{PGL}_2(q)$, $\operatorname{PSL}_3(p)$, and $\operatorname{PSU}_3$)
No finite simple proper left Bol loop $Q$ satisfies $\operatorname{LMlt}(Q) \cong G$ for any of:
1. **$G = \operatorname{PSL}_2(q)$ or $G = \operatorname{PGL}_2(q)$ for all prime powers $q \ge 4$**:
   - *$\operatorname{SL}_2(q)$ ($q = 2^f \ge 4$)*: $G$ has a unique inner involution class $I_1$ of size $q^2 - 1$: $\tau = \mathrm{id}_G$ gives $\Lambda = I_1$ ($h = q$ even, while distinct commuting unipotent involutions in $\mathbb{F}_q^+$ multiply into $I_1$, so $I_1 \subseteq I_1^2$, contradiction) or $\Lambda = \{1\} \cup I_1$ ($q^2 \nmid q(q^2 - 1)$ since $\gcd(q, q^2 - 1) = 1$). An outer involution in $\operatorname{Out}(G) \cong C_f$ exists iff $f = 2e$ ($q = q_0^2$, unique field involution $\phi$). By Hilbert's Theorem 90 / Lang–Steinberg on connected $\mathbf{SL}_2$, $H^1(\langle \phi \rangle, \operatorname{SL}_2(q_0^2)) = 1$, so $\phi G$ has a single involution class $\Lambda = \phi^G$ with $|C_G(\phi)| = |\operatorname{SL}_2(q_0)| = q_0(q_0^2 - 1)$ even, excluded by Theorem 1.1(4).
   - *$\operatorname{PSL}_2(q)$ ($q = p^f \ge 5$ odd)*: Inner involutions form a single class $I_1$ of size $\frac{q(q \pm 1)}{2}$ ($q \equiv \pm 1 \pmod 4$) with $h = q \mp 1$ even and $V_4 \le \operatorname{PSL}_2(q) \implies I_1 \subseteq I_1^2$; $\{1\} \cup I_1$ has size $\frac{q^2 \pm q + 2}{2}$, which fails to divide $\frac{q(q^2 - 1)}{2}$ ($q(q^2 - 1) = (q \mp 1)(q^2 \pm q + 2) - 2(q \mp 1)$ with $0 < 2(q \mp 1) < q^2 \pm q + 2$ for $q > 5$, and $22 \nmid 60$, $11 \nmid 60$ at $q = 5$). In $\operatorname{Out}(\operatorname{PSL}_2(q)) \cong C_2 \times C_f$:
     * *Diagonal outer coset ($\operatorname{PGL}_2(q) \setminus \operatorname{PSL}_2(q)$)*: Trace-$0$ non-square-determinant matrices form a single $G$-class $\Lambda$ of size $\frac{q(q \mp 1)}{2}$, giving $h = q \pm 1$ even, excluded by Theorem 1.1(4).
     * *Pure field involution $\phi$ ($q = q_0^2$)*: Involutions in $\phi G$ split into two $G$-classes $O_1, O_2$ of size $\frac{1}{2} q_0(q_0^2 + 1)$ swapped by $\operatorname{PGL}_2(q_0^2)$, giving even $h \in \{q_0(q_0^2 - 1), \frac{1}{2} q_0(q_0^2 - 1)\}$. For $V_4 \le \operatorname{PGL}_2(q_0) = C_G(\phi)$, the $4$ involutions $\{\phi v : v \in V_4\} \subseteq O_1 \sqcup O_2$ force some $1 \neq v \in O_i^2$ by Pigeonhole, and $\operatorname{PGL}_2(q_0^2)$-symmetry gives $I_1 \subseteq O_1^2 \cap O_2^2$, contradicting $h$ even.
     * *Diagonal-times-field coset ($q = q_0^2$)*: If $M \in \operatorname{GL}_2(q_0^2)$ satisfies $M^\phi M = \lambda I_2$, then $M^\phi = \lambda M^{-1} \implies M = \lambda^\phi (M^\phi)^{-1} = \frac{\lambda^\phi}{\lambda} M \implies \lambda \in \mathbb{F}_{q_0}^\times$ ($\lambda^{q_0 - 1} = 1$). Taking determinants gives $(\det M)^{q_0 + 1} = \lambda^2$, whence $(\det M)^{\frac{q_0^2 - 1}{2}} = \bigl((\det M)^{q_0 + 1}\bigr)^{\frac{q_0 - 1}{2}} = (\lambda^2)^{\frac{q_0 - 1}{2}} = \lambda^{q_0 - 1} = 1$, so $\det M \in (\mathbb{F}_{q_0^2}^\times)^2$ and $\bar{M} \in \operatorname{PSL}_2(q_0^2)$. Thus the diagonal-times-field outer coset contains **zero involutions**.
   - *$\operatorname{PGL}_2(q)$ ($q = p^f \ge 5$ odd)*: Inner classes of $x^2 = 1$ are $I_0 = \{1\}$, $I_{\mathrm{in}} \subset \operatorname{PSL}_2(q)$ ($\frac{q(q \pm 1)}{2}$), and $I_{\mathrm{out}} \subset \operatorname{PGL}_2(q) \setminus \operatorname{PSL}_2(q)$ ($\frac{q(q \mp 1)}{2}$). Applying Theorem 1.1(3) with $G_+ = \operatorname{PSL}_2(q)$ eliminates $I_{\mathrm{in}}$ and $I_{\mathrm{out}}$ alone, leaving $I_0 \cup I_{\mathrm{out}}$ ($|\Lambda| = \frac{q^2 \mp q + 2}{2}$: since $2q(q^2 - 1) = (2q \pm 2)(q^2 \mp q + 2) \mp 2(2q \pm 2)$, we have $q(q^2 - 1) \equiv \mp(2q \pm 2) \not\equiv 0 \pmod{\frac{q^2 \mp q + 2}{2}}$ for $q \ge 7$, and $11 \nmid 120, 16 \nmid 120$ at $q = 5$), $I_{\mathrm{in}} \cup I_{\mathrm{out}}$ ($|\Lambda| = q^2 \nmid q(q^2 - 1)$), and $I_0 \cup I_{\mathrm{in}} \cup I_{\mathrm{out}}$ ($|\Lambda| = q^2 + 1 \nmid q(q^2 - 1)$ as $\gcd(q^2 + 1, q(q^2 - 1)) \le 2 < q^2 + 1$). In $\operatorname{Aut}(\operatorname{PGL}_2(q)) = \operatorname{P\Gamma L}_2(q)$, the unique outer involution $\phi$ ($q = q_0^2$) has all involutions of $\phi \operatorname{PGL}_2(q_0^2)$ inside the single coset $\phi \operatorname{PSL}_2(q_0^2)$ (just proved above), failing Theorem 1.1(3).
2. **$G = \operatorname{PSL}_3(p)$ for all primes $p \ge 2$**:
   For $p = 2$, $\operatorname{PSL}_3(2) \cong \operatorname{PSL}_2(7)$ is covered by (1). Assume $p \ge 3$ is an odd prime. $G$ has a unique inner involution class $I_1$ of size $p^2(p^2 + p + 1)$ ($h$ even, and $\operatorname{diag}(-1, -1, 1), \operatorname{diag}(1, -1, -1)$ give $I_1 \subseteq I_1^2$). For $I_0 \cup I_1$, $|\Lambda| = p^4 + p^3 + p^2 + 1$ is coprime to $p^3$, and $(p^2 - 1)(p^3 - 1) = (p - 1)(p^4 + p^3 + p^2 + 1) - (p^3 + p^2 + p - 2)$ with $0 < p^3 + p^2 + p - 2 < p^4 + p^3 + p^2 + 1$, so $|\Lambda| \nmid |G|$. In $\operatorname{Out}(\operatorname{PSL}_3(p)) \cong C_{\gcd(3, p-1)} \rtimes C_2$, the unique conjugacy class of outer involutions is represented by transpose-inverse $\tau(A) = (A^T)^{-1}$. Any involutory $\tau \bar{M}$ lifts to $M \in \operatorname{SL}_3(p)$ with $(M^T)^{-1} M = \omega I_3$ ($\omega^3 = 1$); transposing gives $\omega^2 = 1 \implies \omega = 1$, so $M^T = M \in \operatorname{SL}_3(p)$. Over $\mathbb{F}_p$ ($p$ odd) in odd dimension $3$, all symmetric matrices of determinant $1$ form a single $\operatorname{SL}_3(p)$-congruence class $M = B^T B$ ($B \in \operatorname{SL}_3(p)$, scaling by $-I_3$ if $\det B = -1$), so $\tau G$ has a unique involution class $\Lambda = \tau^G$ with $|C_G(\tau)| = |\operatorname{SO}_3(p)| = p(p^2 - 1)$ even, excluded by Theorem 1.1(4).
3. **$G = \operatorname{PSU}_3(p)$ for all odd primes $p \ge 3$, and $G = \operatorname{PSU}_3(2^{2^s})$ for all $s \ge 1$**:
   - *Inner $\tau = \mathrm{id}_G$*: For odd $p \ge 3$, $G$ has a unique involution class $I_1$ of size $p^2(p^2 - p + 1)$ ($h$ even, $V_4 \le G \implies I_1 \subseteq I_1^2$), and $|I_0 \cup I_1| = p^4 - p^3 + p^2 + 1$ is coprime to $p^3$ with $(p^2 - 1)(p^3 + 1) = (p + 1)(p^4 - p^3 + p^2 + 1) - (p^3 + p + 2)$ ($0 < p^3 + p + 2 < p^4 - p^3 + p^2 + 1$). For $q = 2^{2^s}$ ($s \ge 1$, $3 \nmid q + 1$, $\operatorname{PSU}_3(q) = \operatorname{SU}_3(q)$), $G$ has a unique unitary transvection class $I_1$ of size $(q - 1)(q^3 + 1)$ ($h = q^3(q + 1)$ even; commuting transvections in a $1$-dimensional isotropic root center of order $q \ge 4$ give $I_1 \subseteq I_1^2$), and $|I_0 \cup I_1| = q(q^3 - q^2 + 1)$ fails to divide $q^3(q^2 - 1)(q^3 + 1)$ since $\gcd(q^2, q^3 - q^2 + 1) = 1$ and $(q^2 - 1)(q^3 + 1) = (q^2 + q)(q^3 - q^2 + 1) - (q^2 + q + 1)$ ($0 < q^2 + q + 1 < q^3 - q^2 + 1$).
   - *Outer involutions*: Let $q = p$ (odd prime $p \ge 3$, $\operatorname{Out}(G) \cong C_2$ or $S_3$) or $q = 2^{2^s}$ ($s \ge 1$, $\operatorname{Out}(G) \cong C_{2^{s+1}}$); in both cases $\operatorname{Out}(G)$ has a unique conjugacy class of involutions, represented in an orthonormal Hermitian basis ($J = I_3$, $F(X) := (X^{(q)T})^{-1}$ on $\mathbf{SL}_3(\overline{\mathbb{F}}_q)$ with $\mathbf{SL}_3^F = \operatorname{SU}_3(q)$) by the field involution $\phi_0(X) = X^{(q)}$. Every involutory $\phi_0 \bar{M}$ lifts to $M \in \operatorname{SU}_3(q)$ with $(\phi_0 M)^2 = \omega I_3$: since $\omega^q = \omega$ and $\omega^3 = \omega^{q+1} = 1$, we get $\omega = 1$, so $M^{(q)} M = I_3 = (M^T)^{-1} M^{(q)} \implies M^T = M$. Because the dimension $3$ is **odd**, $M = C^T C$ for some $C \in \mathbf{SL}_3(\overline{\mathbb{F}}_q)$ (in characteristic $2$, odd-size invertible symmetric matrices are never alternating). Then $F(M) = M$ implies $Z := C F(C)^{-1} \in \mathbf{K} := \{X \in \mathbf{SL}_3(\overline{\mathbb{F}}_q) : X^T X = I_3\}$. Now **$\mathbf{K}$ is a connected algebraic group**: for odd $p$, $\mathbf{K} = \mathbf{SO}_3$ with $|C_G(\phi_0)| = |\operatorname{SO}_3(p)| = p(p^2 - 1)$ even (every $\phi_0$-fixed $Z(\operatorname{SU}_3(p))$-coset has a unique representative in $\operatorname{SO}_3(p)$); for $q = 2^{2^s}$, every $A \in \mathbf{K}$ fixes the unique vector $v_0 = (1, 1, 1)^T$ representing $w \mapsto \sqrt{w^T w}$ and preserves the nondegenerate rank-$2$ alternating form on $v_0^\perp$, so $\mathbf{K} \cong \mathbf{Sp}_2 = \mathbf{SL}_2$ is connected with $|C_G(\phi_0)| = |\operatorname{SL}_2(q)| = q(q^2 - 1)$ even. By the Lang–Steinberg Theorem on connected $(\mathbf{K}, F|_{\mathbf{K}})$, $Z = Y^{-1} F(Y)$ for some $Y \in \mathbf{K}$, so $B := Y C \in \mathbf{SL}_3^F = \operatorname{SU}_3(q)$ satisfies $B^T B = M$ ($(\phi_0 B)\phi_0(\phi_0 B)^{-1} = \phi_0 M$). Hence $\phi_0 G$ has a **unique** involution class $\Lambda = \phi_0^G$ with $|C_G(\phi_0)|$ even, excluded by Theorem 1.1(4). $\square$

### 3. Universal CFSG-Free Exclusion of $\operatorname{LMlt}(Q) \cong A_m$ and $S_m$ ($m \ge 5$)

#### Theorem 3.1 (No Simple Proper Left Bol Loop Has $\operatorname{LMlt}(Q) \cong A_m$ or $S_m$ for Any $m \ge 5$)
For every integer $m \ge 5$, no finite simple proper left Bol loop $Q$ satisfies $\operatorname{LMlt}(Q) \cong A_m$ or $\operatorname{LMlt}(Q) \cong S_m$.

*Proof*:
1. **Small degrees $5 \le m \le 8$ and reduction to cycle-type unions ($m \ge 9$)**:
   Degrees $m \in \{5, 6, 7, 8\}$ (including all five groups $A_6, S_6, \operatorname{PGL}_2(9), M_{10}, \operatorname{P\Gamma L}_2(9)$ in $\operatorname{Aut}(A_6) = \operatorname{P\Gamma L}_2(9)$) have zero valid folders by direct finite check (`code/test_lmlt_exclusions.py`). Assume $m \ge 9$, so $\operatorname{Aut}(A_m) = \operatorname{Aut}(S_m) = S_m$ and $Z(S_m) = 1$. By Theorem 1.1, a faithful folder $(G, H, K)$ ($G \in \{A_m, S_m\}$, $|K| > 2$, $|H| \ge 2$) yields $t \in S_m$ ($t^2 = 1$) such that $\Lambda := t K \subseteq \{x \in S_m : x^2 = 1\}$ is $G$-conjugation invariant in $t G$ with $|\Lambda| \cdot |H| = |G|$ and $H \cap \Lambda^2 = \{1\}$.
   Let $C_k \subset S_m$ ($0 \le k \le \lfloor m/2 \rfloor$) be the class of cycle type $2^k 1^{m-2k}$ ($|C_k| = \frac{m!}{2^k k! (m - 2k)!}$). For $k \ge 1$, every $\lambda \in C_k$ commutes with one of its own transpositions in $S_m \setminus A_m$, so no $C_k$ splits in $A_m$. Thus $\Lambda = \bigcup_{k \in J} C_k$ for a nonempty $J \subseteq \{0, 1, \dots, \lfloor m/2 \rfloor\}$ with $k_{\max} := \max(J) \ge 1$, where $J$ has **pure parity** if $G = A_m$ ($\Lambda \subseteq t A_m$) and **mixed parity** if $G = S_m$ ($t \in \Lambda$ and $K = t \Lambda \not\subseteq A_m$ by Theorem 1.1(3)).

2. **Exact cycle-product lemmas**:
   - **Lemma 3.2 ($C_{2r} \subseteq C_k^2$)**: *For all $1 \le k \le \lfloor m/2 \rfloor$ and $1 \le r \le \min(k, \lfloor m/4 \rfloor)$, $C_{2r} \subseteq C_k^2$.*
     *Proof*: If $2r \le k$, on $r$ disjoint $4$-tuples $\{a_i, b_i, c_i, d_i\}$ and $k - 2r$ disjoint pairs $\{u_j, v_j\}$ ($2k \le m$), $\alpha = \prod_{i=1}^r (a_i, c_i)(b_i, d_i) \prod_{j=1}^{k-2r} (u_j, v_j) \in C_k$ and $\beta = \prod_{i=1}^r (a_i, d_i)(b_i, c_i) \prod_{j=1}^{k-2r} (u_j, v_j) \in C_k$ satisfy $\alpha \beta = \prod_{i=1}^r (a_i, b_i)(c_i, d_i) \in C_{2r}$. If $r \le k < 2r$, put $s = 2r - k > 0$ and $t' = k - r \ge 0$ ($s + 2t' = k$, $4(s + t') = 4r \le m$); on $s$ disjoint $4$-tuples $\{p_i, q_i, p'_i, q'_i\}$ and $t'$ disjoint $4$-tuples $\{a_j, b_j, c_j, d_j\}$, $\alpha = \prod_{i=1}^s (p_i, q_i) \prod_{j=1}^{t'} (a_j, c_j)(b_j, d_j) \in C_k$ and $\beta = \prod_{i=1}^s (p'_i, q'_i) \prod_{j=1}^{t'} (a_j, d_j)(b_j, c_j) \in C_k$ give $\alpha \beta \in C_{2r}$. $\square$
   - **Lemma 3.3 ($C_{(3)} \subseteq C_k^2$)**: *For all $1 \le k \le \lfloor (m - 1)/2 \rfloor$, the $3$-cycle class $C_{(3)}$ satisfies $C_{(3)} \subseteq C_k^2$.*
     *Proof*: Since $2k + 1 \le m$, $(x_1, x_2) \prod_{j=1}^{k-1}(y_j, z_j)$ times $(x_2, x_3) \prod_{j=1}^{k-1}(y_j, z_j)$ equals $(x_1, x_2, x_3) \in C_{(3)}$. $\square$

3. **Regime I: $k_{\max} \ge \lfloor m/4 \rfloor$ ($m \ge 9$)**:
   By Lemma 3.2, $\operatorname{Inv}(A_m) = \bigcup_{r=1}^{\lfloor m/4 \rfloor} C_{2r} \subseteq C_{k_{\max}}^2 \subseteq \Lambda^2$. Since $H \cap \Lambda^2 = \{1\}$, $|H \cap A_m|$ is odd. By Dixon's Theorem (J. D. Dixon, *Canad. Math. Bull.* **10** (1967), 503–505, Thm. 1, via Feit–Thompson), an odd-order subgroup of $S_n$ has order $\le 3^{(n-1)/2}$; decomposing $\{1, \dots, m\}$ into $r$ orbits of odd sizes $n_1, \dots, n_r$ under $H \cap A_m$ ($r \ge 1$ for odd $m$, $r \ge 2$ for even $m$) gives $|H \cap A_m| \le \prod_{i=1}^r 3^{(n_i - 1)/2} = 3^{(m - r)/2} \le 3^{\lfloor (m - 1)/2 \rfloor}$.
   Put $I(m) := \sum_{k=0}^{\lfloor m/2 \rfloor} |C_k|$ (so $|\Lambda| \le I(m)$, and $|\Lambda| < I(m)$ when $G = A_m$) and $R(m) := \frac{I(m) \cdot 2 \cdot 3^{\lfloor (m - 1)/2 \rfloor}}{m!}$. From $I(m) = I(m - 1) + (m - 1)I(m - 2)$, we get $R(m) \le \frac{3}{m}(R(m - 1) + R(m - 2))$ for both parities of $m$. Exact integer evaluation gives $R(10) = \frac{9496 \cdot 162}{3628800} = \frac{1187}{2800} < 1$ and $R(11) = \frac{35696 \cdot 486}{39916800} = \frac{6693}{15400} < 1$, whence $R(m) < 1$ for all $m \ge 10$ by induction, forcing $|\Lambda| \cdot |H| < |G|$ for both $A_m$ and $S_m$. At $m = 9$, checking all subsets $J \subseteq \{0, 1, 2, 3, 4\}$ with $k_{\max} \ge 2$ gives $0$ mixed-parity divisibility hits in $S_9$ and $4$ pure-parity hits $J \in \{\{2\}, \{3\}, \{1, 3\}, \{4\}\}$ in $A_9$ with $|H| \in \{480, 144, 140, 192\}$ — all even, contradicting $|H|$ odd.

4. **Regime II: $1 \le k_{\max} < \lfloor m/4 \rfloor$ ($m \ge 9$)**:
   By Lemmas 3.2 and 3.3, $C_{(3)} \cup C_2 \subseteq C_{k_{\max}}^2 \subseteq \Lambda^2$, so $H \cap (C_{(3)} \cup C_2) = \emptyset$.
   - **Lemma 3.4 (Reduction to minimal degree $\mu(H_0) \ge 5$)**: No element of $H$ has support $3$ ($C_{(3)}$) or $4$ ($C_2$ or $4$-cycles squaring into $C_2$). If $H$ contains a transposition $\sigma = (a, b)$, no other transposition lies in $H$ (else their product lies in $C_{(3)} \cup C_2$), so $\sigma \in Z(H)$ and $H = \langle \sigma \rangle \times H_0$ where $H_0 \le \operatorname{Sym}(\{1, \dots, m\} \setminus \{a, b\})$ satisfies $\mu(H_0) \ge 5$; otherwise $H_0 := H$ satisfies $\mu(H_0) \ge 5$. In both cases $|H| \le 2 |H_0|$.
   - **Lemma 3.5 (Subdirect diagonal structure)**: By induction on $r$, every subdirect product $L_0 \le \prod_{t=1}^r S_t$ of nonabelian simple groups is a direct product $\prod_{u=1}^k D_u$ of full diagonal subgroups over a partition $\{1, \dots, r\} = I_1 \sqcup \dots \sqcup I_k$ (using $Z(S_r) = 1$).
   - **Lemma 3.6 (CFSG-free order bound for $\mu(H_0) \ge 5$)**: On each nontrivial $H_0$-orbit $\Omega_i$ ($n_i = |\Omega_i| \ge 2$), pick a minimal nontrivial block system $\mathcal{B}_i$ ($N_i$ blocks of size $d_i = n_i / N_i \ge 2$) so the block-stabilizer local action $P_i \le S_{d_i}$ is primitive:
     1. $\mathcal{A}$ ($d_i \ge 5, A_{d_i} \le P_i$, point sum $a$): $N_i \le n_i / 5$;
     2. $\mathcal{N}_{\ge 5}$ ($d_i \ge 5, A_{d_i} \not\le P_i$, point sum $b$): by Praeger–Saxl (*Bull. London Math. Soc.* **12** (1980), 303–307, Thm. 1, CFSG-free), $|P_i| < 4^{d_i}$, so $|P_i|^{N_i} < 4^{n_i}$ and $N_i \le n_i / 5$;
     3. $\mathcal{N}_2$ ($d_i = 2$, even point sum $c'_2$): $|P_i|^{N_i} = 2^{n_i/2}$, $N_i = n_i / 2$;
     4. $\mathcal{N}_{3,4}$ ($d_i \in \{3, 4\}$, point sum $c'_{34}$): $|P_i|^{N_i} \le 24^{n_i/4}$ ($6^{1/3} < 24^{1/4}$), $N_i \le n_i / 3$.

   - **Analytical closure for all $m \ge 42$**: Put $q := \lfloor m/4 \rfloor \ge 10$. For $1 \le k \le q$, $\frac{|C_{k-1}|}{|C_k|} = \frac{2k}{(m - 2k + 2)(m - 2k + 1)} < \frac{2}{m}$, so $|\Lambda| \le \sum_{k=0}^{q-1} |C_k| < \frac{2}{m - 2}|C_q|$. Replacing each $\lfloor x \rfloor!$ in $(\dagger)$ by $\tilde{\Gamma}(x) := \max(1, \Gamma(x + 1))$, Bohr–Mollerup convexity of $\ln \tilde{\Gamma}$ makes the log-upper-bound convex on the simplex $a + b + c_2 + c_{34} = m$ ($a, b, c_2, c_{34} \ge 0$), so its maximum occurs at one of the four vertices:

   - **Finite range $9 \le m \le 41$**: Two auxiliary CFSG-free caps handle the remaining hits:
