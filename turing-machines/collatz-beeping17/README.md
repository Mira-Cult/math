# 17-state Collatz beeper: package moved

The complete [machine, writeup, ordinary mathematical proof, provenance,
attribution and finite checkers](../collatz/beeping17/README.md) now live in
`turing-machines/collatz/beeping17/`, alongside the other Collatz machines.

The machine is unchanged. This old [literal table URL](collatz_beeping17.tm)
is retained as a byte-identical compatibility copy and checked by the family
release checker. Other files are canonical only in the new package.

[Migration details](../collatz/MIGRATION.md).
