## Return geometry

For every final terminal path and every prepared suffix, the recorded maximum
zero run is five. Lexical return only truncates a path or changes a zero to
one before the left scan starts. Thus the six-zero detector cannot stop
inside any admitted path. Starting to the right of the root, it eventually
crosses the finite root and observes six cells in the blank left margin.
The unchanged right scan then reaches the same root. The return changes no
tape symbols and has the same tape/head/root exit relation. It terminates
for every finite admitted path. The maximal path length is 29 and the
